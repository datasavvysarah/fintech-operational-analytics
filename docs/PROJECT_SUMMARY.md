# Operational Turnaround & Bottleneck Reporting Pipeline
## Project Summary

---

## Problem Statement

**For:** Hizo, Vent Africa, Trazo

Operations teams waste **hours manually combing through disjointed logs** when transactions stall:
- **Hizo:** Cross-border payment delays across settlement rails
- **Vent Africa:** Crypto off-ramp KYC/bank processing bottlenecks
- **Trazo:** Merchant order fulfillment delays

**Solution:** Automated pipeline that consolidates operational data, diagnoses exact bottleneck stages, and enables proactive resolution.

---

## What's Been Built

### 1. **Realistic Synthetic Data Generator** (`data_generator.py`)
Generates 18,000 realistic operational records modeling actual company workflows:

| Company | Data Type | Records | Key Metrics |
|---------|-----------|---------|------------|
| **Hizo** | Cross-border payments | 5,000 | Country pairs, settlement banks, currency conversion stages |
| **Vent Africa** | Crypto off-ramp | 3,000 | User tiers, KYC verification, bank processing latency |
| **Trazo/Hizo** | Merchant orders | 4,000 | Payment methods, warehouse locations, fulfillment stages |
| **All Companies** | API logs | 6,000 | Endpoint latencies, external API dependencies |

**Data Quality:**
- 88.9% Hizo completion rate (realistic ~10% failure)
- 87.8% Vent Africa completion rate (realistic KYC failures)
- 85.9% Merchant order completion rate (realistic warehouse delays)
- 90.2% API success rate (realistic 2-3% error margin)

### 2. **PostgreSQL Analytics Schema** (`database_schema.sql`)
Production-ready schema with:
- **5 main tables** (transactions, hizo_payments, vent_offramp, merchant_orders, api_logs)
- **Indexed columns** for fast querying (company, status, date, endpoints)
- **5 pre-built analytical views** for Power BI/Tableau

**Key Views:**
```sql
v_transaction_bottlenecks -- Completion rates, P95/P99 latencies by company/type
v_company_daily_metrics -- Daily volume & performance trends
v_api_performance -- Endpoint health (P95/P99 response times)
v_hizo_settlement_analysis -- Settlement partner bank ranking
v_vent_africa_kyc_analysis -- KYC bottleneck by user tier
```

### 3. **Data Ingestion Pipeline** (`data_ingestion.py`)
Python ETL script that:
- Reads CSV files generated by data_generator.py
- Validates and transforms datetime columns
- Loads into PostgreSQL (18,000 records ~5 seconds)
- Indexes all key columns for fast queries

### 4. **Quick Analysis Tool** (`quick_analysis.py`)
No-database-required analysis showing:

**Hizo Insights:**
- Average processing: 14.3s (P95: 52.6s)
- Settlement stage longest: 9.33s avg
- Bank performance: Access Bank slowest (15.64s latency)
- Top route: Rwanda→Botswana (16.55s avg)

**Vent Africa Insights:**
- Average processing: 16.9s (P95: 71.2s)
- KYC verification: 2.95-3.13s (all tiers similar)
- Bank latency: 23s (main bottleneck!)
- Failure breakdown: insufficient_balance (26%), bank_timeout (25%), invalid_account (26%), kyc_failed (23%)

**Merchant Fulfillment Insights:**
- Average order cycle: 12.04s (P95: 31.6s)
- Slowest stage: Payment Processing (5.14s)
- Lagos warehouse fastest (11.6s), Nairobi slowest (12.3s)
- Mobile money slowest payment method (12.38s)

**API Health:**
- Overall P95 response: ~5s (healthy)
- Slowest endpoint: GET /api/balance (8.8s P95)
- Success rate: 90.2% across all companies
- External API dependency: 23.6% of request latency on avg

## Insights & Recommendations

### For Hizo (Cross-Border Payments)
1. **Settlement stage is the bottleneck** (9.33s avg)
 - Action: Negotiate SLAs with banks, implement direct API connections
2. **Access Bank slowest** (15.64s latency)
 - Action: Reduce routing through Access Bank, use GTBank (14.80s) more
3. **Rwanda↔Botswana route slow** (16.55s avg)
 - Action: Review PAPSS routing, add local partners

### For Vent Africa (Crypto Off-Ramp)
1. **Bank processing is the bottleneck** (23s avg)
 - Action: Add bank timeout retries, implement async processing queue
2. **Bank timeouts = 25% of failures**
 - Action: Implement circuit breaker pattern, fallback payment gateway
3. **KYC not the bottleneck** (2.95-3.13s for all tiers)
 - Action: Can safely increase KYC rigor for tier_3 users

### For Merchant Fulfillment
1. **Payment processing is the bottleneck** (5.14s avg, 43% of total time)
 - Action: Batch payment processing, implement payment queue
2. **Mobile money slower** (12.38s vs 11.71s bank_transfer)
 - Action: Investigate mobile money provider latency
3. **Warehouse variability** (11.6s-12.3s range)
 - Action: Share best practices from Lagos to other warehouses

### For All Companies
1. **API endpoints slow** (P95: 4.6-8.8s)
 - Action: Add response caching, implement async patterns
2. **External API latency** (~24% of request time)
 - Action: Rate limiting, connection pooling, regional endpoints
