QUICK START COMMANDS
================================================================================

1. View Analysis Without Database (30 seconds)
   $ python3 quick_analysis.py

2. Generate Fresh Data (if needed)
   $ python3 data_generator.py

3. Set Up PostgreSQL (requires local PostgreSQL)
   $ createdb operational_analytics
   $ psql operational_analytics < database_schema.sql
   $ python3 data_ingestion.py

4. Verify Data Loaded
   $ psql operational_analytics -c \
     "SELECT COUNT(*) FROM transactions;"

5. Connect Power BI/Tableau
   Server: localhost
   Port: 5432
   Database: operational_analytics
   Username: postgres
   Then query: SELECT * FROM v_transaction_bottlenecks
